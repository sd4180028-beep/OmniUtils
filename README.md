# OmniUtils — Signal Toolkit

A responsive, client-side utility suite for text transformation: repeat strings at scale, encode text into shareable links, and lock content inside password-protected QR codes. Built around a distinct "instrument panel" visual identity — an ink-navy base, an amber signal accent, and monospace treatment for all generated output.

## Design

| Element | Detail |
|---|---|
| **Background** | Deep ink-navy (`#0b1220`) |
| **Primary accent** | Amber signal (`#f5a623`) — primary actions |
| **Secondary accent** | Teal (`#2dd4bf`) — secondary states and focus rings |
| **Headings** | Space Grotesk |
| **Body copy** | Inter |
| **Generated output** | JetBrains Mono — applied to repeated text, links, and decrypted content |
| **Layout** | Fixed left sidebar with three numbered modules (01 / 02 / 03), collapsing into a slide-in drawer on mobile |
| **Signature element** | Animated "trace" mark in the logo — a signal line running through peaks and troughs, echoing the encode/decode theme |

## Modules

### 01 · Text Repeater
Repeat any string up to 10,000 times, with a configurable line-break or space separator and one-click copy.

### 02 · Secret Link Encoder
Wrap text into a shareable `omni://decode?data=...` link, and decode any link generated by the tool directly on the page.

### 03 · Password-Protected QR Studio
AES-encrypt text into a QR code, then upload a QR image and decrypt it back using the correct password.

## Getting Started

1. Clone or download this repository.
2. Ensure you have an active internet connection (required for CDN-hosted fonts, icons, and the QR/encryption libraries).
3. Open `index.html` directly in your browser — no build step or server required.

## Security

All encryption runs entirely in-browser using AES symmetric encryption via JavaScript. No text, passwords, or QR data are transmitted to a server at any point.
